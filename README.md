# The-Attack

## Pip's Big Leap

A side-scrolling platformer built for iPad (and any browser). Run, stomp enemies, bonk `?` blocks for power-ups, and reach the flag in three worlds: **Sunny Meadow**, **Crystal Caverns** and **Lava Keep**.

Everything is in a single file, `index.html`. There are no dependencies and no build step.

### Play it

- **On a computer:** open `index.html` in a browser.
- **On an iPad:** host the repo with GitHub Pages (Settings → Pages → deploy from `main`), open the link in Safari, then Share → **Add to Home Screen** for full-screen play. Hold the iPad sideways for the widest view.

### Controls

| Action | Touch | Keyboard |
| --- | --- | --- |
| Move | ◀ ▶ pad (bottom left) | ← → or A D |
| Jump (hold for higher) | **A** | Space, ↑, W or Z |
| Run / throw fire | **B** (hold to run, tap to throw) | X or Shift |
| Pause | ⏸ top right | P or Esc |
| Sound on/off | Pause menu | M |

### What's in it

- Blobs to stomp, beetles whose shells you can kick, bees, and spiky critters you can only hit with fire
- Power-ups: the Puffcap makes Pip big and able to smash bricks; the Ember Bloom lets Pip throw fireballs
- Springs, moving platforms, lava pits and spinning fire bars
- Checkpoint flags mid-level, a 1-up every 100 coins, and stomp combos
- Chiptune music and sound effects generated live with Web Audio (on iPad, sound needs the silent switch off)
- Worlds unlock as you clear them, and your best score is saved on the device
